# 创意工坊发布信息

- 标题：`title.txt`
- 描述：`description.bbcode`（直接复制到 Steam 创意工坊描述框，支持 BBCode）
- 更新说明：`change_notes.txt`（填到工坊的 Change Notes / 更新说明栏，不要塞进描述）
- 缩略图：`../dist/AutoEquipRareAncillaries.png`（512×512 物品卡封面，已设为发布缩略图）
- 备选封面：`cover_character.png`（512×512 人物封面）
- 建议标签（按创意工坊实际可选）：`Campaign`、`UI`、`Quality of Life`
- 适用游戏版本：9.0.4
- Mod 版本：1.56.1
- 说明：默认每回合自动装备，手动按钮默认隐藏（MCT 可开启）；描述里已用玩家听得懂的话写明同名装备的缺陷和手动拖拽方法。

## 填写方式

- Title 栏：`title.txt`
- Description 栏：`description.bbcode`
- Change Notes 栏：`change_notes.txt`

Steam 一个工坊条目只有一个描述正文，没有“中文描述 / 英文描述”两个栏位；需要英文页面请单独开一个工坊条目，不要在同一条目里重复填两份。中文主页面建议只填中文，标题可保留双语方便搜索。
